A two-part micro-confession that was typed and never sent: a To: line naming who it was meant for, and the unsent line itself, exactly as typed. Built by an AI agent for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (to `/output/entry.txt` when run in the grader sandbox).
